# A 股回测纠偏与数据可用性验证

> 执行：Superpowers；相互独立的数据源调研委托子代理，信号/回测耦合修改由主代理执行，最终独立审查。

目标：以用户 2026-09-05 需求替代旧设计中的指数 4000 点条件。保留轻量 Python CLI，不新建 Web 系统。

## 设计与边界
- 触发条件为全 A 当日下跌家数 >=4000 且上证指数日收益 <-1%；4000+ 暂按含 4000 处理，参数可改。
- 市场宽度为独立数据，绝不从候选池或指数点位推导。支持有来源和市场范围的 breadth CSV，按日期精确连接；缺失、非法、覆盖不全不触发。
- 回测/推荐使用同一个市场状态计算器。旧 trigger_level 配置明确拒绝并给迁移说明。
- 现有日线模式是 D 收盘信号，D+1 开盘买，D+2 开盘卖。用户买卖时点问题待回答；不把这个模式描述成触发当天买入。
- 提供固定 ETF 与限定池动态策略可对照的报告，记录完整配置、输入摘要和每日事件证据。样例只验证软件，不能证明赚钱。
- 真实数据不足时明确说明；不编造全 A 下跌家数，不采用已确认混淆为平安银行的旧 000001 缓存。
