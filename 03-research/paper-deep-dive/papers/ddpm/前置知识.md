# DDPM 前置知识

> 读这篇论文前，你只需要 4 个前置概念。每个都直接挂钩到论文里的具体位置。

---

## 1. 生成模型在做什么？—— 从噪声到数据

生成模型的目标：学会一个分布 p(x)，使得从中采样能生成逼真的数据（图像、音频等）。

常见思路：
- **GAN**：训练一个生成器和一个判别器互相对抗
- **VAE**：学习一个编码器把数据压到潜空间，再学一个解码器重建
- **扩散模型（DDPM）**：**逐步加噪声把数据变成纯噪声，再学怎么逐步去噪声**

**挂钩论文**：DDPM 的核心就是"先破坏再重建"。引言里说"diffusion process gradually adds noise to the data until signal is destroyed"，然后"learn to reverse this process"。

---

## 2. 马尔可夫链是什么？—— "只看当前，不看历史"

马尔可夫链是一个随机过程，**下一步只依赖当前状态，与过去无关**。

```
x₀ → x₁ → x₂ → ... → x_T
```

每一步的转移是随机的：x_{t+1} ~ p(x_{t+1} | x_t)

**挂钩论文**：DDPM 的前向过程（加噪声）和反向过程（去噪声）都是马尔可夫链。第 2 节式 (1) 和式 (2) 就是在定义这两条链。

---

## 3. 高斯噪声与"加噪-去噪" —— 核心机制

**前向过程（加噪声）**：每一步往图像上加一点高斯噪声

```
x_t = √(1−β_t) · x_{t−1} + √β_t · ε
       └── 衰减原信号 ──┘   └─ 加新噪声 ─┘
```

- β_t 控制噪声强度（从 0.0001 线性增到 0.02）
- 经过 T=1000 步后，x_T 几乎是纯噪声

**关键技巧（式 4）**：由于高斯分布的可加性，可以**一步到位**从 x₀ 算出任意时刻的 x_t：

```
x_t = √ᾱ_t · x₀ + √(1−ᾱ_t) · ε
```

其中 ᾱ_t = ∏_{s=1}^{t} (1−β_s)。这个公式让训练时可以随机采样任意 t，不用真的跑 1000 步。

**挂钩论文**：第 2 节式 (4)。这是 DDPM 高效训练的关键。

---

## 4. 反向过程与"预测噪声" —— 学习的核心

**目标**：学会反向过程 p_θ(x_{t−1}|x_t)，从噪声一步步还原数据。

**关键洞察（式 11）**：与其直接预测 x_{t−1} 或 x₀，不如**预测噪声 ε**：

```
μ_θ(x_t, t) = (1/√α_t)(x_t − [β_t/√(1−ᾱ_t)] ε_θ(x_t, t))
```

这里 ε_θ 是神经网络，输入是加噪后的 x_t 和时间步 t，输出是预测的噪声。

**为什么预测噪声更好？**
- 当 t 很小时，x_t 和 x₀ 差别很小，直接预测 x₀ 容易过拟合
- 噪声 ε 是标准高斯，尺度一致，网络更容易学
- 训练目标简化为均方误差：`‖ε − ε_θ(x_t, t)‖²`

**挂钩论文**：第 3.2 节。这是 DDPM 最核心的参数化选择。

---

## 5. U-Net 与时间嵌入 —— 网络架构

DDPM 用 U-Net 作为 ε_θ 的骨干网络：

```
输入 x_t → 下采样（压缩）→ 中间层 → 上采样（恢复）→ 预测噪声
              └────── 跳跃连接 ──────┘
```

- **U-Net**：下采样提取全局特征，上采样恢复细节，跳跃连接保留高分辨率信息
- **时间嵌入**：把时间步 t 编码成向量，注入每个残差块，让网络知道"现在加了多少噪"

**挂钩论文**：第 4 节"To represent the reverse process, we use a U-Net backbone..."。附录 B 有更多细节。
