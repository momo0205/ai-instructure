# ResNet 前置知识

---

## 0a. 卷积是什么？—— 一个小窗口在图上滑动打分

**卷积 = 一个小窗口（filter，比如 3×3）在图像上逐格滑动，每到一个位置就做一次"窗口内对应元素相乘、全部相加"，得到一个数。** 扫完整张图，得到一张新的图（特征图）。

```
图像 4×4          窗口 3×3        输出 2×2
┌─────────┐    ┌─────┐
│ 1  0  2 1│    │1 0 1│    位置1: 1·1+0·0+2·1+0·0+1·1+3·0+2·1+1·0+1·1 = 7
│ 0  1  3 2│  ⊗ │0 1 0│  = ┌────┐
│ 2  1  1 0│    │1 0 1│    │ 7  ?│
│ 1  0  2 1│    └─────┘    │ ?  ?│
└─────────┘                └────┘
```

- **filter 里的数就是该层的权重 W**——训练就是在学这几个数
- **通道**：彩色图有 3 通道（RGB）；"64→128" 表示 64 张输入特征图 → 128 个 filter → 128 张输出特征图
- **stride**：窗口每次移动几格；stride=2 时输出尺寸减半（下采样）

**为什么用它**：一张 224×224 图接全连接要几千万参数。卷积靠两条假设压到 9 个：
1. **局部性**：边缘、纹理等有用模式都在小邻域里
2. **平移共享**：同一个模式出现在哪都一样 → 同一个 filter 扫全图

filter 学到的是"模式探测器"：浅层探测边缘，深层探测完整物体。**这就是"特征层次"，也是引言说"深度至关重要"的原因。**

**挂钩论文**：ResNet 主路里的"weight 层"就是 3×3 卷积层，没有新东西。

## 0b. 堆叠层是什么？—— 一层接一层，字面意思

"堆叠层"（stacked layers）就是**把多个层首尾相接：前一层的输出直接当后一层的输入**。和"串联"完全同义，只是行业习惯译法。

**在 ResNet 里**：
- 一个残差块内的"几个堆叠层" = shortcut 跨过去的那 2~3 个卷积层
- 整个网络 = 更多块的堆叠。ResNet-34 的层数：1 + 6 + 8 + 12 + 6 + 1 = 34（对照论文表 1）

**挂钩论文**：3.1 节"让几个堆叠的层拟合残差映射 F(x)"，指的就是 shortcut 包住的这两三个卷积层。

## 1. 神经网络在算什么？—— 一层就是一次"线性变换 + 非线性弯曲"

每一层做的事用一行式子就能写完：

```
输出 = σ(W · 输入 + b)
```

- `W · 输入` 是**线性变换**（矩阵乘法，旋转+拉伸空间）
- `σ` 是**非线性激活函数**（比如 ReLU：`max(0, x)`，把负值掰成 0）
- 没有 σ，多少层叠起来都等价于一层（线性套线性还是线性）。**非线性是让网络能拟合复杂东西的关键**。

**挂钩论文**：ResNet 第 3.1 节的 `F = W2 σ(W1 x)` 就是这个——两个线性层 W1、W2，中间夹一个 ReLU（σ）。

## 2. 网络怎么"学习"？—— 梯度下降 + 链式法则

学习 = 不断调整 W 让预测误差变小。怎么调？**算误差对每个 W 的偏导数（梯度），往梯度的反方向挪一小步**。

关键在**链式法则**：误差对第 1 层 W 的梯度 = 误差对第 2 层的梯度 × 第 2 层的局部导数 × ... 一路乘回去。

```
∂L/∂W₁ = ∂L/∂y · ∂y/∂h₂ · ∂h₂/∂h₁ · ∂h₁/∂W₁
         └──────┬──────┘
          一长串导数相乘
```

**挂钩论文**：这就是 ResNet 要解决的核心问题的来源。如果链很长（层很深）：
- 每个导数都 < 1 → 连乘后梯度趋近 0 → **梯度消失**，浅层几乎不更新
- 每个导数都 > 1 → 连乘后爆炸 → **梯度爆炸**

**这是引言里"vanishing/exploding gradients"的全部含义**。你不需要会推，只需要知道：深层 = 梯度要连乘很多次 = 容易出问题。

## 3. "退化问题"是什么？—— 论文真正要解决的核心

这是 ResNet 最关键的洞察，也是最容易和上面混淆的。论文花了很大力气区分两件事：

| | 梯度消失/爆炸 | 退化问题（degradation） |
|---|---|---|
| 是什么 | 梯度数值变得极大或极小 | **更深的网络训练误差反而更高** |
| 能否被解决 | 已被 BN、好的初始化基本解决 | **没被解决**——这才是 ResNet 的靶子 |
| 论文证据 | — | 图 1：56 层比 20 层训练误差更高 |

**关键直觉（引言里那段）**：理论上，56 层网络完全可以"假装"自己是 20 层——多出来的 36 层只要学会"什么都不做"（恒等映射，输入=输出）就行了。这样它至少不会比 20 层差。

**但实际上做不到**。求解器（SGD）就是找不到这个"恒等映射"的解。这说明：**问题不是表达能力不够，而是优化器不会学**。

**ResNet 的解法（这就是全部核心）**：既然让网络直接学"输入=输出"很难，那就**改学"输出 − 输入"（残差）**。如果恒等是最优的，残差就是 0——把权重学成 0 比学成恒等映射容易得多。

```
原来要学：H(x) = x        （难）
现在改学：F(x) = H(x) − x = 0   （容易，权重往 0 压就行）
最终输出：F(x) + x = H(x)  （加回输入）
```

那个"+x"就是 shortcut 连接——它不带任何参数，只是把输入原样加到输出上。

## 4. 一个看懂图 2 的最小心智模型

论文图 2 那个方块图，翻译成大白话：

```
        输入 x
          │
    ┌─────┴─────┐
    │           │
  [weight层]    │  ← 主路：学残差 F(x)
  [relu]        │
  [weight层]    │
    │           │
    └───(+)────┘  ← 捷径：把 x 原样加回来
          │
        输出 = F(x) + x
```

主路负责学"需要改多少"（残差 F(x)），捷径负责"原样保留输入"。两者相加。
