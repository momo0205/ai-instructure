# DDPM 最小复现：简化版扩散模型

## 目的

验证 Q3：逐步去噪可以学会生成；网络预测噪声 eps 等价于预测 x_{t-1} 的均值。

## 运行

    python3 ddpm/simple_ddpm.py

## 实现要点

- 前向：x_t = sqrt(alpha_bar_t) x_0 + sqrt(1 - alpha_bar_t) eps（一步到位，式 4）。
- 训练：随机 t，MSE(eps_pred, eps)（简化损失，式 14）。
- 采样：按式 (7) 递推 x_{t-1}，t>0 时再加 sqrt(beta_t) 噪声。
- U-Net：3 层下采样 + 3 层上采样 + 跳连，正弦时间嵌入注入每层。

## 观察

| 指标 | 数值 |
|------|------|
| 起始 mse | 0.0952 (step 100) |
| 结束 mse | 0.0559 (step 800) |
| 生成样本是否像数字 | 是（可见数字笔画/曲线结构，但仍模糊，800 步欠训练） |

训练在 CPU 上运行，800 步约几分钟。损失整体呈下降趋势（0.0952 → 0.0559），
中间有小幅波动（随机 t 与 mini-batch 所致）。生成样本保存在 `ddpm/samples.png`，
可见类似数字的笔画结构（如 1、7、弧线和圈），但边缘模糊、结构不完整——
这是 tiny U-Net + 仅 800 步训练的预期表现。

## 动手实验

1. 把 T 从 100 改成 300，采样质量是否更好？耗时增加多少？
2. 把 `pred` 改成直接预测 x0，损失改成 MSE(x0_pred, x0)，对比效果。
3. 采样时永远不加噪声（DDIM 的确定性版本），看结果有何不同。
4. 只训练 100 步就采样，观察"欠训练"的模糊结果。

## 备注：测试容差说明

`test_diffusion.py` 中 `test_q_sample_limits` 使用 T=1000（标准 DDPM 步数），
因为 T=100 时 alpha_bar[T-1] ≈ 0.36（仅约 64% 噪声），不满足"接近纯噪声"的
紧容差；T=1000 时 alpha_bar[T-1] ≈ 4e-5，t=T-1 才真正接近纯噪声。
t=0 的容差为 0.05，因为 beta_start=1e-4 会注入 sqrt(1e-4)*noise = 0.01*noise。
