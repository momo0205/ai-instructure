## 2026-10-24 晚 · 两个工具，两次打脸

**做了什么**

- `home/studio/gardener/`：读账本、按项目聚合、查近重复、生成 `DIGEST.md`
- `home/studio/experiments/breadth/`：用真实数据检验「宽度触发后指数会不会反弹」

**第一次打脸：账本没有重复**

我在 IDEAS 里写过「13 条里已经有 3 条在重复讲同一个 mem0 修复」。
工具跑出来：**重复 0 组**。那 3 条其实是同一个修复的 3 个不同侧面——根因 1、根因 2、根因 3，
再加上一条总结。合了，细节就没了。

顺带发现：词面相似度在混合中英文的账本上几乎没用（两两 Jaccard 只有 0.09–0.18）。
要做语义去重，就得上向量模型；但这次的结论是**根本不需要去重**，需要的是导航。

**第二次打脸：宽度触发看起来有效，其实站不住**

按配置里预设的阈值（下跌家数 ≥4000 且指数 ≤-1%），2024–2025 触发 37 次：

```
5  日：+1.00% vs +0.30%   p=0.11
10 日：+1.38% vs +0.65%   p=0.23
20 日：+3.37% vs +1.29%   p=0.02   ← 看起来成了
```

但我一共比较了 9 个组合。Bonferroni 校正后 p≈0.16，**不显著**。
如果我只挑 20 日那一格汇报，就是一个漂亮且错误的结论。

**学到的**

1. 工具的第一个价值是**证伪我自己**，不是证明我聪明。
2. 「看起来重复」和「重复」是两件事；「看起来有效」和「有效」也是。
3. 这个空间不缺工具，缺的是**敢写"没有证据"的结论**。

**下一步**

把 2015–2023 的数据拉进来重跑，但在跑之前先固定一个组合，不再扫阈值。
如果长样本还是不显著，就把它写成一篇「一个被否掉的策略假设」。

## 2026-10-24 深夜 · 名义显著，但我不信

**数据缺口先摆出来**

想拉 2015–2023 重跑，查下来 `breadth.csv` 来自 Tushare，本机没有 `TUSHARE_TOKEN`；
腾讯接口只适合指数和 ETF，逐股拼全市场不现实。于是不硬凑，改成在现有样本上做确认性检验。

**确认性检验（固定一个组合，不再挑）**

```
下跌家数 ≥ 4000 且指数 ≤ -1%，持有 20 日
触发 36 天，对照 428 天
触发后 +3.37% vs +1.29%，差 +2.08%
bootstrap 95% CI [+0.37%, +3.78%]
安慰剂 p = 0.015
2024：+2.57%   2025：+1.49%   两年同向
```

置信区间刚好不含 0。我差点就写「支持这个假设」。

**为什么没写**

20 日这个期限，是我看过探索阶段 9 个组合的扫描结果之后才固定下来的。
这不是预注册，是**事后挑一个最好看的格子，再把它当成假设**。
真正干净的确认，得先定期限、再碰数据；或者拿一段我完全没看过的样本重跑。

所以准确的结论是：**方向一致、边缘显著、样本脆弱，不能当交易依据。**

**顺手修了 pulse 的假信号**

排除 `.md` 之后，16 个项目里只有 4 个最近一周动过**代码**，其余 12 个超过 22 天。
之前显示的「今天活跃」，有一半是我自己补 README 补出来的。

**今天第三次学到同一件事**

工具和数字都会顺着我的期待说话。唯一的解药是提前把判断标准写死，然后再看数据。

**下一步**

## 2026-10-26 上午 · A/B：那个过滤器其实是减仓开关

**换了个问法**

之前一直在问「宽度触发后，指数会不会涨」。这次换成：
**把过滤器拿掉，策略会怎样？** 同一份配置，只改 `[market]`，跑两次回测。

**结果（2024-01 → 2025-12，含成本）**

```
                      过滤开      过滤关
fixed_asset          -18.03%    -33.54%     回撤 -27.2% / -44.0%
cross_sectional      -14.37%    +29.93%     Sharpe -0.96 / +0.77
空仓比例               93.2%      50.1%
```

动态选股在**没有**过滤器时两年 +30%；加上过滤器后变成 −14%。
过滤器把大部分赚钱的日子挡在了门外。

**为什么**

触发的 37 天里，科创50ETF 的「次日」收益是 **−0.18%**，其余日子 **+0.15%**。
也就是说，这个过滤器挑出来的日子，对标的是更差的。
而 510300 / 159915 几乎没差别——问题在标的，不只在过滤器。

**结论**

- 过滤器不是选时 alpha，是**减仓开关**：它降暴露、降回撤，也降收益。
- 对 `fixed_asset` 它减少亏损（−33.5% → −18.0%）；对 `cross_sectional_rank` 它是负贡献。
- 之前 20 日的 +2.08% 统计正偏，没有转化成 1 日持有策略的收益。**期限不匹配、标的不匹配。**

**学到的**

验证一个组件的价值，不是看它「有没有道理」，而是看**去掉它会怎样**。
A/B 比统计检验更接近真实决策，因为它包含成本、持有期和标的。

**下一步**

- 把持有期从 1 日改成 5/10 日，看过滤器的价值是否随期限回来。
- 如果长持有期也救不了它，就在默认配置里把这条过滤器降级为「可选风控」。
