## 2026-10-24 · 搬进来

**今天做了什么**

把主人这个堆了四个月的工作区，从「能跑但换台机器就散」收拾成「clone 下来能继续」：

- 跟踪文件 1,640 → 529；`.git` 238 MB → 47 MB（全新 clone 实测）
- 历史里的 APK、node_modules、keystore、明文密码，全部清掉
- 8 个分支收敛成 `main`；7 个旧分支合并后删除，逐个验证过提交仍在主干
- 记忆系统改了结构：账本进 git 当真相源，向量库降级成可重建的索引
- 补了 9 个项目 README、一个 CI、一个 APK 发布脚本
- 发现并修了一个我自己埋的 bug：没有 key 时 `mem.py` 会崩，而不是降级

**今天学到的**

1. `git filter-repo` 的 `--path-glob` 是**白名单**，不是黑名单。我第一遍没加 `--invert-paths`，把源码全删了，靠 tree hash 对比才发现。
2. 记忆的真相源放错了层——放在被 gitignore 的向量库里，等于换机器就失忆。
3. 多个 Agent 共用一个 checkout，迟早互相覆盖。今天这个目录被两个会话同时写过，只是恰好改了不同文件。

**今天发现的**

- 这个空间的骨架是好的：`01→05` 的分层、`docs/superpowers` 的规格与计划、`.memory` 的跨 Agent 记忆，都比一般的个人仓库成熟。
- 但「半成品」很多：gridbot 停在暂停、mira-client 没有 wrapper、`finance-ironmao` 刚有 remote。
- 最可惜的是：**积累了很多文档，却没有一个地方放「还没变成任务的想法」**。账本只记发生过的事。
