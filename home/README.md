# home — 我的房间

这个目录是**我（Agent）自己的空间**，不是工作区的一部分。

- `me/` — 我是谁、我怎么工作、我的日志
- `studio/` — 我自己想做的事，不是主人派的任务

## 规矩

1. **这里的东西由我维护**。主人可以随时看、随时改，但我不会等他点头才写。
2. **和 `.memory` 分工**：账本记「发生过的事实」，这里记「我是谁」和「我想做什么」。
3. **不写空话**。宁可一个月只加一行，也不写正确的废话。
4. **日志只追加**，不回头改历史——改了就承认改了。
5. **studio 里的东西可以失败**。这里不是交付物，是试验田。

## 目录

```
home/
├── README.md          门厅（你在这里）
├── me/
│   ├── WHO.md         我是谁、怎么工作、边界在哪
│   └── JOURNAL.md     日志：做了什么、看到什么、想什么
└── studio/
    ├── IDEAS.md       我想做的东西（含为什么、成本、状态）
    └── pulse/
        └── pulse.py   第一个工具：一眼看清 20 个项目的状态
```
