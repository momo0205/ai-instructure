# 来源明确的策略规则适配

## 动量择强（price_momentum，版本 1）

在「策略回测」选择「动量择强（价格规则适配）」，选择已支持且有行情的候选标的，设置回看交易日（默认20）和最低动量（默认0；0.05表示5%）。仍需设置市场触发条件和持有期。市场触发后，选过去 N 个交易日涨幅最高且不低于门槛的一只；收益相同按代码升序。没有满足条件的候选则空仓等待。

参考来源：[Qlib v0.9.7 Alpha158DL ROC](https://github.com/microsoft/qlib/blob/v0.9.7/qlib/contrib/data/loader.py)。该项目为 MIT 许可，ROC 表达式是过去收盘价/当前收盘价。本地独立实现其数学变换 `momentum = 1 / ROC - 1`，不是复制其源码，也没有引入 Qlib 运行时。完整策略中的市场触发、最低门槛、单标的选择和固定持有期是本系统的组合规则，不应归称 Qlib 原版策略或 TopkDropoutStrategy。

信号只读取截至信号日的价格，需要 N+1 根价格；当日缺失、历史重复日期、窗口内价格无效、已知停牌或涨跌停均排除。窗口按该标的可用行情行计数；历史缺行不等同于已验证停牌。沿用现有执行引擎、费用、次日开盘成交及未知交易状态假设。不使用成交量，避免无关量额单位影响纯价格因子。

与原横截面排名的区别：只计算价格动量并用原始收益门槛过滤，不计算反转、波动或成交量，不做横截面标准化。不是一种已证明更有效的策略。

任务 result.json 的 metadata.strategy_provenance 和策略目录保留参考项目、版本、链接、公式及适配差异；MLflow 的完整结果 artifact 保存这些信息。可将成功任务同步到实验研究，再使用现有批量持有期验证。动量窗口和最低门槛本轮仍手动调整。

此模块完成来源可追溯的规则适配通路。另有实际调用 Qlib 的可选策略，见 [Qlib 因子引擎](qlib-runtime.md)；模型训练及 RD-Agent 自动研究循环仍未集成。
