# 普通 A 股近似回测 Implementation Plan

> 按已批准方案执行 subagent-driven-development / TDD，沿用功能分支。先交付近似研究；不宣称严格成交验证。

**Goal:** 协鑫能科可从已有行情数据集中选择并完成有费用、执行记录与限制说明的回测。

**Architecture:** 引擎增加可选逐标的交易类型规则，旧调用默认不变；工作台识别普通沪深主板股票并启用版本化规则，ETF 保持零印花税。执行日志独立于市场触发日志，结果展示费用拆解。原始数据不修改、不自动联网。

**Scope:** 主板股票代码000/001/002/003.SZ及600/601/603/605.SH，需有已识别名称和stock元数据；当前名称含ST/退的证券不开放（不保证历史状态识别）。创业板、科创板、北交所、未知证券仍拒绝。支持股票研究日期2022-07-01起；更早规则未实现，明确拒绝。当前模式固定approximate，不提供假严格模式。

- [x] TDD引擎：可选 instrument_types mapping；股票100股买入、至少下一交易日卖出；股票按卖出日2023-08-28前0.001、之后0.0005计印花税；2022-07-01起过户费双边0.00001；佣金视为含交易规费、不含过户费和印花税。买入数量预留费用，防止负现金。结果独立execution_events记录成交/取消/延后及费用。
- [x] TDD工作台：普通股票目录支持，排除特殊类型；最早日期校验；混合候选逐标的费用；执行假设、规则版本、费用说明写入metadata。股票仅approximate，unknown交易状态不作可交易证明。
- [x] 成交语义：缺行/无效开盘/已知停牌不可成交；股票买入涨停受阻，卖出跌停受阻；卖出受阻下一交易日再试，买入失败取消。未知标志False按近似假设可成交并全局警告；不从前复权价格反推法定涨跌停，不用收盘/全天成交量决定开盘成交。
- [x] 前端：支持范围与近似模式提示；已识别股票进入下拉；逐笔显示费用拆解与执行记录，兼容旧结果。
- [x] 验收：历史税率边界、T+1、费用不足、买卖阻断/延后、ETF不变、股票与ETF混选；全测试、真实协鑫能科任务及浏览器；文档、提交。

依据：印花税法 https://fgk.chinatax.gov.cn/zcfgk/c100009/c5193058/content.html ，税率说明 https://tianjin.chinatax.gov.cn/11200000000/0300/030005/20220725150235434.shtml ，减半公告 https://www.sse.com.cn/aboutus/mediacenter/hotandd/c/c_20230827_5725662.shtml ，费用表 https://one.sse.com.cn/onething/gptz/ ，深交所2023规则 https://docs.static.szse.cn/www/lawrules/rule/allrules/bussiness/W020230217564423808793.pdf 。复权价、日频撮合、状态未知及未建模分红/股本变化均为研究假设，不能等同券商账单。


补充用户确认：费用必须为独立模块，状态数据获取与交易判断也应解耦。实现 `fees.py`（规则表、日期匹配、费用拆解、预算、版本元数据）和 `tradability.py`（三态状态、可替换 StatusProvider、近似资格判断）。引擎仅负责订单、持仓和资金演进，保留旧调用兼容代理。
