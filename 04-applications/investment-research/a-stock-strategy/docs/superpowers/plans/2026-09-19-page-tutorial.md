# 页内研究教程

目标：让用户从页面理解任务、实验、批量验证和 MLflow 的关系，并自行完成一次研究流程。

设计：采用原生 details，主页默认展开短路线图；实验页提供完整步骤、具体时间切分示例及结果解读。复用 data-tab-target 导航，不新增 API、依赖或自动提交任务。不改变回测规则。

执行：
- [x] index.html 添加全局入门入口、实验页教程和结果解释。
- [x] style.css 添加局部教程排版，移动端单列。
- [x] 浏览器验证教程展开/收起、导航与移动端宽度；既有 Node 检查验证导航无破坏。

主线：单次回测（已有）→ 实验归档比较（已有）→ 批量持有期与前后段验证（已有）→ 多参数研究与更严格稳健性验证（后续）→ AI 基于可追溯证据提出研究建议（后续）。本次完善已有批量研究的使用闭环，不扩展选参算法。
