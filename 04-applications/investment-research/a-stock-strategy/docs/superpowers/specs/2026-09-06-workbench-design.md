# 个人回测工作台设计

用户已确认本机单人使用、日频单持仓、现有两种策略、动态参数、任务历史与结果展示。继续在 codex/a-stock-breadth-mvp 工作目录推进，复用已有真实数据。

## 模块边界

- registry.py：策略目录、参数类型与范围、版本、构造策略。新策略只需注册，页面读取参数定义。
- workbench.py：数据集目录、请求验证、预热数据、执行与结果。数据集只允许来自项目 data 目录，页面不接收任意文件路径。
- jobs.py：SQLite 持久化任务；一个后台执行线程串行处理任务，每次任务独立目录。阶段为 queued/running/succeeded/failed/cancelled；进程重启将未完成任务标记 interrupted。
- web.py：仅绑定 127.0.0.1，标准库 HTTP 服务提供 JSON API 和同源静态页面。拒绝跨源写操作与非 JSON 请求。
- static/：原生 HTML/CSS/JavaScript；不依赖 CDN。策略表单、任务列表、结果详情、净值与回撤 SVG、任务指标对比、配置复制。
- market_download.py：正式腾讯历史行情下载入口，保留原始响应、字段验证、日期过滤与来源清单；Tushare 广度沿用现有下载器。

## 执行约定

请求含 strategy_id、parameters、dataset_id、start、end 及公共执行参数。以注册数据集为边界，检查候选标的和交易日覆盖；数据不足拒绝执行或明确报告预热不足。历史预热数据供策略使用但不在所选区间内交易。每次任务冻结请求、策略版本、输入文件副本与哈希；旧结果不被新任务覆盖。第一版退出方式仍为固定持有期。

数据准备与回测分开：现有数据集直接可选，正式 CLI 支持下载新数据；页面明确显示可用日期、来源、复权和样例标记。不承诺当前数据之外的日期自动可用。

## 页面与 API

GET /api/strategies、/api/datasets、/api/jobs、/api/jobs/{id}；POST /api/jobs；POST /api/jobs/{id}/cancel；结果 API 提供指标、净值、交易、事件、警告、请求快照。页面每两秒查询任务，无需保持浏览器开启。

现有测试保持通过；新增参数非法、缺失日期/标的、预热截止、任务隔离与重启、取消、API 错误测试。浏览器完成选择策略、改参数、运行、看图、复制和对比。代码注释解释公式单位、时序、并发和失败行为。
