# 累计数据覆盖与时间轴

用户已确认：在现有模块内建设覆盖计算、缺口计划、基础快照组装；旧回测输入不变。

- 指数及市场广度跨不可变版本累计；同日期相同数据去重，不同数据标冲突并阻止该日期用于自动研究。
- 覆盖按实际日期计算。保留提供方空工作日证据作为非交易日观察，不将无响应当休市。尚无独立交易日历认证。
- 行情与基础取交集，按连续可用交易区间展示；策略预热和执行能力仍由回测验证。
- 股票前复权版本不拼接；同证券可展开每个版本的行情和可研究区间。
- 更新请求先规划，默认仅获取缺失的指数/广度日期段。完全覆盖时不需要凭据或联网；旧版本及来源保留。
- 研究准备在服务端重新计算覆盖，组装完整冻结基础，复用现有研究发布和回测引擎。
- 时间轴在数据管理中展示指数、广度、共同覆盖、证券行情和可研究区间，缺口可带入补齐表单，研究区间可带入回测。
- 兼容旧 real、managed 和 asset 数据；坏版本隔离，扫描以文件状态缓存避免重复读取所有表格。
