# 实验追踪最小集成

用户已确认：保留现有回测，优先接入 MLflow 实验记录和比较。采用独立解释器调用 MLflow SDK，不引入 Qlib/RQAlpha 到生产依赖。

成功的网页回测自动进入独立同步队列；持久化状态为 pending/synced/failed，服务重启恢复 pending。历史成功任务可手动同步。运行失败或取消的回测不作为成功实验导出。同步异常使用固定公开提示，原结果不变。

每个任务使用 job ID 作为幂等键，MLflow run ID 在创建后立即保存，以便失败重试复用；子进程写入 SQLite 数据库和本机 artifact 目录。记录请求参数、数据和源码哈希、策略版本、核心指标、基准与随机对照摘要以及完整 result.json。只导出显式文件，不采集环境变量或 Git diff。

配置来自服务启动参数（解释器、MLflow 页面地址），浏览器不能传入文件路径、解释器或目标服务。页面从现有任务接口读取同步状态，提供同步/重试和 MLflow 页面入口。比较使用 MLflow 自带 UI，保留现有任务比较。

验收：默认关闭无额外依赖；自动同步不会阻塞回测线程；异常可感知可重试；并发重试无重复；重启可恢复；真实 MLflow 查询记录、参数、指标、artifact 与回测一致。仅当前网页工作台任务自动同步，旧式 CLI backtest 本轮不接入。
