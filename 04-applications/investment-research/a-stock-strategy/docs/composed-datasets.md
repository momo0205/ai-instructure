# 组合研究数据集

当两只证券分别下载到不同扩展数据集时，可以在「数据管理 → 组合研究数据集」把它们组成一个研究输入。无需重新下载。

1. 指数与市场广度基线选择现有基础数据集。
2. 勾选协鑫能科 `002015.SZ`、贵州茅台 `600519.SH`；在各自来源下拉框选择已有扩展版本。
3. 点击「检查组合」，查看共同覆盖区间、交易日数量、复权方式和来源限制。
4. 点击「创建组合数据集」，生成独立版本。创建不会自动回测，也不会覆盖旧数据。
5. 点击「使用组合数据回测」，选择 Qlib 动量择强或横截面排名，再同时选择这两只股票作为候选。资金应足以覆盖目标股票最小买入数量及费用。

支持2–20只不重复证券，每只只取一个版本，不拼接同代码历史。拒绝合成数据、未知/不同复权方式、共同区间内缺行情、指数或广度基线冲突。共同区间按起止覆盖交集计算，不用删除中间缺失日期凑齐数据。预览与创建之间源文件变化会要求重新检查。

组合后的市场/广度CSV与证券元数据独立保存，旧数据不变。来源CSV与清单归档在组合目录的 `sources/`，各来源哈希保存在 `market_manifest.json`。原始下载响应及嵌套证据没有递归复制，仍依赖原数据版本；`symbol_sources.*.original_dataset_root` 明确原版本路径，归档清单中的相对路径仍按原清单语义解释，不相对归档位置解释。移动或备份项目时应保留原数据版本；组合自身CSV可独立用于回测，但不等同于包含全部原始供应商证据。

组合不会统一或修正各证券的历史复权基准、量额单位或未知交易状态，这些限制仍保留在页面与回测结果中。刷新浏览器后组合版本仍在数据目录，已有任务继续使用自己的冻结输入。
