# 数据管理工作台

行情下载与市场基础数据分别管理，研究准备时验证共同覆盖。顶层「数据管理」包含数据概览、证券与行情、市场基础数据、下载与更新任务。

## 下载近期行情

1. 打开「证券与行情」，输入 `600519.SH`，选择需要的日期，例如 `2026-09-01` 至 `2026-09-21`。
2. 提交后在「下载与更新任务」观察识别证券、下载、校验等阶段。网络请求没有可信百分比，因此不显示虚构完成比例。
3. 成功后点击「查看行情与依赖」。检查请求区间、实际覆盖、行数、来源、复权方式、覆盖说明及最多100条行情预览。
4. 近期行情可以保存，即使现有指数/广度只到2025年。此时“当前策略暂不可运行”是依赖状态，不等于下载失败。
5. 下载不会自动开始回测。刷新页面后任务和版本仍在。

当前生产来源为腾讯，独立行情使用前复权日线；来源路由与其他复权方式尚未开放为页面选项。下载代码范围和回测交易规则支持范围分别判断。未来日期拒绝；当日返回数据不保证是终盘，研究准备保守地只使用今天之前的日期。

## 更新与研究

行情详情提供「更新至今日（重新下载完整区间）」和自定义区间。按钮先带回表单，核对后提交；前复权不把新增日期拼到旧版本尾部，更新会创建新版本。

数据依赖齐全时，点击「准备可用区间并带入回测」。系统以已有真实指数与广度为基线，验证共同日期，生成独立研究版本，并带入证券、日期及该版本。此步骤不会执行回测；确认策略和资金后再点击开始回测。允许部分区间研究时，明确显示实际共同范围，不把全部下载区间标记为可用。

新行情版本使用 `data/asset_<id>`，已准备研究版本继续使用 `data/managed_<id>`。旧基线、旧研究数据、旧任务和冻结输入不修改。新研究版本保留来源资产编号与清单；原始响应位于原资产目录，勿随意删除。

## 覆盖与状态含义

- “与本次观测指数日期一致”只代表两份响应中的日期一致，尚未通过独立完整交易日历认证。
- 缺失行情不能自动认定为停牌，也不会通过前向填充制造成交价格。
- 下载成功表示拿到并通过格式及来源校验的行情，实际覆盖以详情为准。
- 当前策略需要指数、市场广度、证券行情及支持的交易规则；缺一项就显示原因。
- 市场基础数据页可以更新指数与广度，显示任务进度、失败原因和版本覆盖。尚无独立交易日历、每日定时调度或备用源自动切换。

## 更新市场基础数据

1. 打开「数据管理 → 市场基础数据」。也可在行情详情点击「补齐市场基础数据」，带入该资产的实际日期。
2. 选择研究需要的完整起止区间，结束日期最多为北京时间昨天。当前单次最多三年。
3. 填写临时 Tushare token；若启动服务时已设置 `TUSHARE_TOKEN`，可留空。临时凭据只驻留后台内存，提交后页面清空，不进入任务数据库、数据文件或日志。
4. 点击「更新指数与市场广度」。腾讯提供上证指数，Tushare daily 提供沪深北股票日线截面，按 `pct_chg < 0` 统计下跌家数。后台按日限速获取，并显示已处理工作日数量。休市空响应也保留，不把缺失日期直接补零。
5. 指数和广度日期一致、文件及原始证据哈希校验通过后，才发布 `data/foundation_<id>`。失败时旧版本保持可用；修正权限或连接问题后重新提交。
6. 回到「证券与行情」，重新打开目标资产详情，点击「准备可用区间并带入回测」，检查证券、日期、资金与策略后提交。

基础版本不可变；系统从单个版本中选择共同交易日最多的可用范围，不自动拼接不同基础版本。需要跨年的完整回测时，请更新覆盖整个研究区间的基础版本。已有 `real` 和历史任务仍然保留原来的日期，不会被修改。

最低每日4000条只排除明显不完整名单，不证明全市场完整。Tushare 日线中停牌证券可能缺席，当前没有独立交易所日历认证。以上限制随来源清单保留。
