01

Mac 本地 · 选择入口

选定起点，准备两个终端

按 ⌘ + 空格，打开“终端 / Terminal”。保留两个窗口：窗口 A 登录 VPS，窗口 B 始终留在 Mac 本地。每个命令块都标明执行地点。

当前状态从哪里开始
已完成 deployer、sudo 与密钥初始化直接第 2 步，不需要重装。
全新 VPS / 确实需要重装先完成旧初始化教程第 1–6 步再回来；跳过旧第 7–10 步，本教程替代旧代理路线。
已有 3X-UI / Xray前半程保留旧服务与 8443 节点，新 443 验收通过后再退役。

保留已有 FlClash 0.8.94，在“关于”核对版本；缺少时从官方 v0.8.94 发布页下载匹配 Mac 架构的安装包。

Mihomo 官方文档不保证与 Xray 26.7.11 及之后版本的 Reality 兼容。实验中新 Xray 的 MLKEM=true 能连通，false 失败，不能概括成所有新 Xray 都失败。本教程选择已实测的 sing-box 1.14.2 + support-x25519mlkem768: false，升级前要重新验证。

Reality 目标无需属于你，节点无需申请自己的 HTTPS 证书。自己的域名与可信证书用于后半程的普通订阅 HTTPS。

成功条件：deployer 密钥登录与 sudo 可用；版本和初始化起点已核对。

下面建立一次初始快照，保留服务 active / enabled 状态和配置。活跃 SQLite 使用 backup API；备份目录只让 root 读取。

窗口 A · VPS 终端 · 一次性初始备份
sudo python3 - <<'PY_BACKUP'
import datetime, json, os, pathlib, shutil, sqlite3, subprocess
state_dir = pathlib.Path('/var/lib/ironmao-proxy')
state_dir.mkdir(mode=0o700, parents=True, exist_ok=True)
os.chmod(state_dir, 0o700)
state_file = state_dir / 'migration.json'
if state_file.exists():
    print('已有初始迁移记录，保留原始回退状态：', state_file)
    raise SystemExit(0)
stamp = datetime.datetime.now(datetime.timezone.utc).strftime('%Y%m%dT%H%M%SZ')
backup = pathlib.Path('/var/backups/ironmao-proxy') / ('initial-' + stamp)
backup.mkdir(mode=0o700, parents=True)
os.chmod(backup.parent, 0o700)
def status(unit, action):
    result = subprocess.run(['systemctl', action, unit], text=True,
                            stdout=subprocess.PIPE, stderr=subprocess.DEVNULL)
    return result.stdout.strip() or 'unknown'
services = {unit: {'active': status(unit, 'is-active'),
                   'enabled': status(unit, 'is-enabled')}
            for unit in ('x-ui', 'caddy', 'sing-box')}
for name, source in [('x-ui', '/etc/x-ui'), ('caddy', '/etc/caddy'),
                     ('sing-box', '/etc/sing-box')]:
    src = pathlib.Path(source)
    if src.exists():
        ignored = shutil.ignore_patterns('x-ui.db', 'x-ui.db-wal', 'x-ui.db-shm') if name == 'x-ui' else None
        shutil.copytree(src, backup / name, ignore=ignored)
db = pathlib.Path('/etc/x-ui/x-ui.db')
if db.exists():
    with sqlite3.connect('file:' + str(db) + '?mode=ro', uri=True) as src:
        with sqlite3.connect(backup / 'x-ui-consistent.db') as dst:
            src.backup(dst)
for name, command in [('listeners.txt', ['ss', '-lntp']),
                      ('ufw.txt', ['ufw', 'status', 'verbose'])]:
    result = subprocess.run(command, text=True, stdout=subprocess.PIPE,
                            stderr=subprocess.STDOUT)
    (backup / name).write_text(result.stdout)
state = {'created_utc': stamp, 'backup_dir': str(backup), 'services': services}
state_file.write_text(json.dumps(state, indent=2) + '\n')
os.chmod(state_file, 0o600)
print('初始备份：', backup)
print('原服务状态：', json.dumps(services, ensure_ascii=False))
PY_BACKUP

成功条件：443 空闲；架构与时间符合要求；初始备份已保存；旧 x-ui 按原状态运行。

04

窗口 A · VPS 终端 · 检查出口

检查 Reality 握手目标

固定目标 dl.google.com:443，两端 SNI 一致。先确认 VPS 本身能访问目标、协商 TLS 1.3 和 h2。

窗口 A · VPS 终端 · 只检查握手目标
timeout 15 openssl s_client -connect dl.google.com:443 -servername dl.google.com -tls1_3 -alpn h2 -verify_return_error < /dev/null

核对 TLSv1.3、ALPN protocol: h2 和证书验证成功。超时、日期或证书错误、缺少 h2 时先处理 VPS 出口、DNS 与时间，不随意改 SNI。

这里只证明 VPS → 目标的 TLS 可用，还未证明 Mac → VPS 代理可用。第 8 步必须验收显式代理的 HTTPS、出口 IP 与服务器日志。

成功条件：可信 TLS 1.3 握手和 h2 协商通过。

05

窗口 A · VPS 终端 · 只生成一次

一次生成服务端与完整客户端配置

完整复制整块命令。它在 VPS 生成 UUID、短 ID 和 Reality 密钥对，备份原配置，写出服务端 JSON 与完整 Mihomo YAML；无需手抄密钥。私钥只留在服务器，客户端中的 UUID、公钥和短 ID 也需要保管。

若客户端文件已存在，生成器拒绝覆盖，直接下载当前文件即可。活动服务或配置目录里其他 JSON 也会触发停止，避免意外轮换或叠加配置。
窗口 A · VPS 终端 · 完整配对生成器
sudo python3 - <<'PY_CONFIG'

server_ip = '23.94.184.3'
sni = 'dl.google.com'
client = pathlib.Path('/home/deployer/ironmao-vps.yaml')
config_dir = pathlib.Path('/etc/sing-box')
config = config_dir / 'config.json'
if client.exists():
    raise SystemExit('停止：客户端文件已存在。保留凭据，直接下载，不要重新生成。')
if subprocess.run(['systemctl', 'is-active', '--quiet', 'sing-box']).returncode == 0:
    raise SystemExit('停止：sing-box 正在运行，先核对用途，不能覆盖活动配置。')
others = [p for p in config_dir.rglob('*.json') if p != config]
if others:
    raise SystemExit('停止：配置目录存在其他 JSON，先核对，不能叠加运行。')
account = pwd.getpwnam('deployer')
service_group = grp.getgrnam('sing-box').gr_gid
result = subprocess.run(['/usr/bin/sing-box', 'generate', 'reality-keypair'],
                        check=True, text=True, stdout=subprocess.PIPE)
keys = dict(line.strip().split(':', 1) for line in result.stdout.splitlines() if ':' in line)
private_key = keys.get('PrivateKey', '').strip()
public_key = keys.get('PublicKey', '').strip()
if not all(re.fullmatch(r'[A-Za-z0-9_-]{43}', key) for key in (private_key, public_key)):
    raise SystemExit('停止：无法识别密钥输出格式，未写入配置。')
user_id = str(uuid.uuid4())
short_id = secrets.token_hex(8)
server = {
    'log': {'level': 'info', 'timestamp': True},
    'inbounds': [{
        'type': 'vless', 'tag': 'vless-in',
        'listen': '0.0.0.0', 'listen_port': 443,
        'users': [{'name': 'ironmao-mac', 'uuid': user_id, 'flow': 'xtls-rprx-vision'}],
        'tls': {
            'enabled': True, 'server_name': sni, 'min_version': '1.3',
            'reality': {
                'enabled': True,
                'handshake': {'server': sni, 'server_port': 443},
                'private_key': private_key, 'short_id': [short_id]
            }
        }
    }],
    'outbounds': [{'type': 'direct', 'tag': 'direct'}],
    'route': {'final': 'direct'}
}
profile = f'''mixed-port: 7890
bind-address: 127.0.0.1
allow-lan: false
mode: rule
log-level: info
ipv6: false
tun:
  enable: false
dns:
  enable: true
  listen: 127.0.0.1:1053
  ipv6: false
  enhanced-mode: fake-ip
  fake-ip-range: 198.18.0.1/16
  default-nameserver:
    - 223.5.5.5
  proxy-server-nameserver:
    - 223.5.5.5
  direct-nameserver:
    - 223.5.5.5
  nameserver:
    - "https://dns.google/dns-query#PROXY"
proxies:
  - name: IRONMAO-Reality-443
    type: vless
    server: "{server_ip}"
    port: 443
    uuid: "{user_id}"
    network: tcp
    tls: true
    udp: false
    flow: xtls-rprx-vision
    servername: "{sni}"
    client-fingerprint: chrome
    reality-opts:
      public-key: "{public_key}"
      short-id: "{short_id}"
      support-x25519mlkem768: false
proxy-groups:
  - name: PROXY
    type: select
    proxies:
      - IRONMAO-Reality-443
rules:
  - IP-CIDR,127.0.0.0/8,DIRECT,no-resolve
  - IP-CIDR,10.0.0.0/8,DIRECT,no-resolve
  - IP-CIDR,172.16.0.0/12,DIRECT,no-resolve
  - IP-CIDR,192.168.0.0/16,DIRECT,no-resolve
  - IP-CIDR,169.254.0.0/16,DIRECT,no-resolve
  - MATCH,PROXY

stamp = datetime.datetime.now(datetime.timezone.utc).strftime('%Y%m%dT%H%M%SZ')
backup_dir = pathlib.Path('/var/backups/ironmao-proxy')
backup_dir.mkdir(mode=0o700, parents=True, exist_ok=True)
os.chmod(backup_dir, 0o700)

这份文件包含 DNS、节点、选择组与规则。首轮互联网流量统一走 PROXY，私有网段直连；组里没有 DIRECT 回退。Google DoH 经节点，223.5.5.5 用于引导与直连解析；引导仍可能有明文 DNS，后续隐私与分流要单独验证。udp: false 把本轮限定为 TCP，游戏、QUIC 与 UDP 应用不在通过范围。

成功条件：整块正常结束，两个配置已写入，未打印真实凭据。

07

窗口 B · Mac + FlClash

下载文件，在 FlClash 选中节点

窗口 B 必须是 Mac 本地终端；本路线下载不需要 SSH 订阅隧道。

窗口 B · Mac 本地终端 · 下载完整配置
umask 077
scp -i "$HOME/.ssh/ironmao_vps" -o IdentitiesOnly=yes deployer@23.94.184.3:/home/deployer/ironmao-vps.yaml "$HOME/Downloads/ironmao-vps.yaml"
chmod 600 "$HOME/Downloads/ironmao-vps.yaml"
  1. 先停止 FlClash 内核，关闭 TUN 与系统代理，模式设为 规则 / Rule；保留旧配置。
  2. 在 工具 → 基本配置 → 端口 检查实际 Mixed / 混合端口。文件写的是 7890，但应用设置可能覆盖端口、模式和 TUN，以实际值为准。
  3. 进入 配置 → 添加 → 文件，选择下载目录里的 ironmao-vps.yaml。
  4. 设为当前 / 激活配置，再启动内核。
  5. 代理页面的 PROXY 组选择 IRONMAO-Reality-443，再次核对 TUN 与系统代理仍关闭。
窗口 B · Mac 本地终端 · 核对监听端口
lsof -nP -iTCP:7890 -sTCP:LISTEN

成功条件：配置激活、新节点选中、TUN 与系统代理关闭，实际 Mixed 端口有监听。

08

窗口 A 看日志 · 窗口 B 发起请求

用显式代理验证真实联网

窗口 A 开实时日志，保持运行；结束按 Control + C。日志可能包含访问目标，分享前删去凭据与私密链接。

窗口 A · VPS 终端 · 保持运行
sudo journalctl -u sing-box -f --since now

窗口 B 逐块验收。curl -q 不读个人 curl 配置，--noproxy '' 清空绕过列表，--proxy 指定 FlClash；保留这些参数。每次请求立即检查退出码。

窗口 B · Mac 本地终端 · HTTPS 204
curl -q --noproxy '' --proxy http://127.0.0.1:7890 --connect-timeout 10 --max-time 30 --silent --show-error --output /dev/null --write-out 'final_http=%{http_code}\n' https://www.gstatic.com/generate_204
printf 'curl_exit=%s\n' "$?"

期望 final_http=204、curl_exit=0。CONNECT 的 200 Connection established 不是最终 HTTPS 成功。

窗口 B · Mac 本地终端 · 正常 HTTPS 内容
curl -q --noproxy '' --proxy http://127.0.0.1:7890 --connect-timeout 10 --max-time 40 --fail --location --silent --show-error --output "$HOME/Downloads/ironmao-proxy-check.html" --write-out 'final_http=%{http_code} bytes=%{size_download}\n' https://www.example.com/
printf 'curl_exit=%s\n' "$?"
wc -c "$HOME/Downloads/ironmao-proxy-check.html"

期望最终 HTTP 200、退出码 0、非空网页，打开文件核对内容为 Example Domain。

窗口 B · Mac 本地终端 · 出口 IP
curl -q --noproxy '' --proxy http://127.0.0.1:7890 --connect-timeout 10 --max-time 30 --fail --silent --show-error https://api.ipify.org
