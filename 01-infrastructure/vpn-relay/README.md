# VPN 中转站部署手册

两份 HTML 手册，记录自建境外节点与中转站的完整部署过程。**纯文档，没有代码。**

## 文件

| 文件 | 内容 |
|---|---|
| `VPN中转站完整部署手册.html` | 主手册：VPS 选型、协议选择、服务端与客户端配置、排障 |
| `ColoCrossing翻墙节点部署手册.html` | 单节点实操：ColoCrossing 机器从开机到可用 |

## 使用

直接用浏览器打开对应 HTML（中文、带图、可离线）。

```bash
open "01-infrastructure/vpn-relay/VPN中转站完整部署手册.html"
```

## 注意

- 手册里含真实的**服务器 IP、端口、域名、UUID/密码**，因此本仓库必须保持私有。
- 配置改过之后请同步更新手册，并回写一条记忆。
